Vaultly help

Vaultly is the team's password manager. Everything is encrypted in your browser with keys derived from your master password: the server only stores ciphertext and cannot read your passwords.

Getting started

  • An administrator sends you an invite link. Open it, enter your name, email and a master password (at least 12 characters; a long sentence works well).
  • Nobody can reset your master password, not even the administrator. If you forget it, your data is gone. Write it down and keep it somewhere safe.
  • You get a private vault called Personal. Shared vaults appear after you accept an invitation in the sidebar.

Items and types

Press + to add an item and pick its type: Login, Note, Card, Identity, Wi-Fi, Bank account, Software license, API key, SSH key, Server / database. Each type has its own fields; secret fields are hidden until you press 👁, and every field has a Copy button. The clipboard is cleared after 30 seconds.

  • Tags: type them comma separated (finance, website). They appear in the sidebar and are searchable (#finance).
  • Custom fields for anything else; tick secret to hide a value.
  • 2FA codes: paste the setup key or otpauth:// link of a website into a login's 2FA field and Vaultly shows the current 6-digit code.
  • Attachments: in the edit form, + Attach files adds files of up to 25 MB each (contracts, certificates, scans). Each file is encrypted in your browser with its own key, which is stored inside the encrypted item; the server keeps only unreadable data. Everyone who can see the item can download the file; viewers cannot add or remove files. A removed file stays on the server for 15 days, so restoring a snapshot brings it back. Encrypted backups do not include files.
  • Password history keeps the last 5 passwords of a login. Trash keeps deleted items until someone deletes them forever.

Password generator

Two modes: random characters (length, character sets, no look-alike characters) and words (a passphrase such as Velvet-Canyon-Trophy7-Mango-Static, easy to type on a phone; 5 words ≈ 65 bits). The word list is the EFF large wordlist.

Shared vaults and roles

  • Create a vault (+ New vault), then open Settings → Vault management to add members by email. The other person must already have an account and must accept the invitation.
  • Roles: Owner (members, settings, snapshots), Editor (add and change items), Viewer (read only).
  • Compare the fingerprint shown when adding someone with the one in their Settings (in person or by phone) to be sure you share with the right person.
  • Removing a member rotates the vault key, so they cannot read anything added later. Passwords they already saw should be changed.

Snapshots (undo for a whole vault)

The server keeps an encrypted copy of every shared vault once a day (before the first change of the day, last 14 days) and before every restore. If items were deleted or overwritten by mistake, an owner opens the vault in Settings → Vault management → Snapshots and presses Restore. Every item goes back to its state at that time, deleted ones included; items added later stay. The state before the restore is saved too, so a restore can be undone. Rotating the key clears older snapshots (they were encrypted with the old key).

Send: share a secret with someone outside the team

Use Send in the sidebar, or the Send… button of an item, to give a password, note or file (up to 10 MB) to someone who has no Vaultly account, e.g. an accountant or a supplier.

  • It is encrypted in your browser with a new key that exists only inside the link. The server cannot read it. Copy the link right away: it cannot be shown again.
  • Choose how long it works (1 hour to 30 days) and how many times it can be opened (default: once). The page only counts a view when the recipient presses Show the secret, so chat apps generating link previews do not use it up.
  • Add a password for extra safety and tell it to the recipient another way (phone). 5 wrong passwords lock the link for 10 minutes.
  • Your active links are listed under the form with their view counts; delete a link to stop it at once. The account activity shows when one was opened.

Account security

Two-factor sign-in

Settings → Two-factor sign-in → Set up (asks for your master password). Scan the QR code with an authenticator app (Aegis, 2FAS, Google or Microsoft Authenticator…), enter the code it shows, and save the 8 recovery codes. From then on, signing in asks for the 6-digit code after the master password. A recovery code works once instead of the code if you lose your phone. If you lose both, an administrator can turn 2FA off for you (Admin → Reset 2FA, which asks for the administrator's own master password) after checking it is really you; it appears in your account activity and your data stays protected by your master password. After 5 wrong codes, two-factor sign-in is locked for 15 minutes.

Signed-in devices and activity

Settings → Signed-in devices lists every browser signed in to your account, with address and last activity. Sign out one device, or all other devices at once (e.g. after using a shared computer). Account activity lists sign-ins, failed sign-ins, 2FA changes and Send links. Many failed sign-ins you did not make mean someone is guessing: keep a strong master password and turn on 2FA.

Auto-lock

Vaultly locks after a period without activity (Settings → Auto-lock, default 10 minutes) and forgets the keys in memory.

Browser extension (autofill)

Fills usernames and passwords on websites in Chrome, Edge, Brave and Opera.

  1. Settings → Browser extension → Download, then unzip the file.
  2. Open chrome://extensions (Edge: edge://extensions), turn on Developer mode, click Load unpacked and choose the unzipped vaultly-extension folder. Pin the Vaultly icon.
  3. Click the icon, keep the server address, enter your email, press Connect and allow access to the server. Unlock with your master password (and 2FA code).

On a website, the extension lists the logins saved for exactly that address. Fill puts the username and password into the form; nothing is filled without your click. A login saved for another site asks first (protection against look-alike sites). Password copies it and clears the clipboard after 30 seconds; 2FA code copies the current code. Search finds every login.

Your master password is never stored. After unlocking, the extension keeps the keys in the browser's memory only; they are gone when the browser closes, the computer locks or is idle for 15 minutes, or you press Lock. The extension appears as a device in Signed-in devices.

Security Scan

Finds weak, reused and old passwords and logins without 2FA. Check all passwords asks Have I Been Pwned whether a password appeared in a known data breach; only the first 5 characters of its SHA-1 hash leave your browser.

Backup, import and export

  • Encrypted backup (Settings): one file with every item you can see, encrypted with a backup password you choose (PBKDF2 + AES-256). It does not depend on this server. Restore adds its items to a vault you choose; nothing is overwritten.
  • Import CSV from Chrome, Bitwarden, Proton Pass, 1Password and similar.
  • Export CSV writes everything in plain text; delete the file when you are done. Prefer the encrypted backup.

For administrators

  • Sign-up is by invite only: Admin → Create invite gives a single-use link valid for 7 days, optionally bound to one email.
  • Disable a user to sign them out and block them; owners should also remove them from shared vaults (this rotates the key).
  • Reset 2FA only after confirming the person's identity. Every admin action is in the activity log.
  • Back up the server's /data/kasa.db, /data/secret.key and the attachment folder /data/att/ (Fly.io volume snapshots are on).

Not included

Master password recovery (impossible by design), mobile app, automatic filling without a click, Firefox / Safari extension, files in encrypted backups.
